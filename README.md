## FAQ

#### How did you come up with the idea for Morse Mode?

We were challenged to make a game in our class, and at the time one team member was wearing a Kim Possible shirt, which made us think of a spy theme. Another team member suggested that since we were learning about coding, we should make a spy themed code game, and we came to the conclusion that our topic would be Morse Code.

#### Do I need to know morse code to use your app?

Not at all! Our app is designed for beginners with no expreience with Morse Code. The Agents Journey is set up to where you get easy letters first, and the difficulty increases with each level.
